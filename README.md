# 🏠 House Price Prediction

A Machine Learning project that predicts house prices based on property features using **Python and Linear Regression**.

## 📌 Project Overview

The objective of this project is to build a machine learning model that predicts the price of a house based on features such as:

* Area (sq ft)
* Number of Bedrooms
* Number of Bathrooms
* Age of House

## 🎯 Objective

To develop a regression model that can estimate house prices from given property characteristics.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook
* Streamlit

## 🤖 Machine Learning Model

**Linear Regression** is used for house price prediction.

### Workflow

1. Load the dataset
2. Explore and understand the data
3. Perform data preprocessing
4. Select features and target variable
5. Split data into training and testing sets
6. Train the Linear Regression model
7. Evaluate the model
8. Predict house prices
9. Create a Streamlit application

## 📊 Dataset

The dataset contains house-related information used to train and test the machine learning model.

**Target Variable:** House Price

## 🌐 Streamlit Application

A Streamlit application was created to allow users to enter house details and get a predicted house price.

### Application Features

* Enter house area
* Enter number of bedrooms
* Enter number of bathrooms
* Enter age of house
* Predict house price
